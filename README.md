## 📖 1. アプリ概要と教育的ねらい

### 💡 開発の背景と目的
現代の高校生は、総合的な探究の時間、総合型選抜・推薦入試の志望理由書作成、プログラミング学習など、**「正解のない問い」**に向き合う機会が急速に増えています。
しかし、一般的な生成AI（ChatGPT等）に相談すると、AIは親切に「模範解答」や「要約」を与えてしまいます。その結果、生徒は**「わかった気」になって思考を停止**してしまい、自らの頭で粘り強く考え抜く力やメタ認知が育ちにくくなるという教育的課題が生じています。

**「ソクラテス・メンター」**は、古代ギリシャの哲学者ソクラテスの「産婆術（問答法）」を現代のLLM技術で再現した探究学習支援アプリです。
- **絶対に答え・解決策・アドバイスを教えません。**
- 生徒の入力した言葉を鏡のように反射し、**「深掘りするための短く鋭い問い」**だけを返します。
- 高校生が自分のモヤモヤした思考を打ち込むことで、**「言語化（外化）」「前提の検証」「メタ認知の活性化」**を強制的に促します。

## 🏗️ 3. 2つの実行形態（ハイブリッド提供）

本プロジェクトは、利用シーンに合わせて**2つの動作形態**を用意しています。

### ①【推奨】完全フロントエンドSPA版 (`index.html`)
- **特徴:** サーバー起動すら不要。ブラウザ（Chrome, Edge等）で `index.html` を開くだけで即座に動作します。
- **メリット:** 完全にPC内で完結（クライアントサイド）。学校の端末やオフライン環境でもデモモードが動き、プライバシーが100%保護されます。
- **技術スタック:** HTML5, Tailwind CSS (CDN), Lucide Icons, JavaScript (ES6+), LocalStorage, Groq REST API (Direct Fetch)

### ②【要件定義書準拠】Streamlit版 (`app.py`)
- **特徴:** Python環境で動作し、Streamlit Community Cloudへワンクリックで無料デプロイ可能。
- **技術スタック:** Python 3.10+, Streamlit, Groq API, Tailwind CSS Injection

## 🚀 4. セットアップと起動方法

### 形態A：完全フロントエンド版（最も簡単・インストール不要）

1. 本フォルダにある [`index.html`](file:///c:/Users/teraoka/Documents/%E3%82%BD%E3%82%AF%E3%83%A9%E3%83%86%E3%82%B9/index.html) をダブルクリックしてブラウザで開きます。
2. または、VS Code等の「Live Server」、あるいはPythonの簡易サーバーで起動します：
   ```powershell
   python -m http.server 8000
   ```
   ブラウザで `http://localhost:8000` にアクセスします。
3. 画面右上の「Groq API設定」からAPIキーを入力すれば、本物の超高速LLM（Llama 3.3）との対話が開始されます（※APIキー未入力でも内蔵シミュレータで動作体験可能）。

### 形態B：Streamlit版の起動

1. **必要なライブラリのインストール**:
   ```powershell

   ```
2. **Streamlitアプリの起動**:
   ```powershell
   streamlit run app.py
   ```
3. ブラウザが自動的に立ち上がり、`http://localhost:8501` でアプリが開きます。

### 🌐 形態C：Streamlit Community Cloudへの無料デプロイ手順

1. 本フォルダのコード（`app.py`, `requirements.txt`, `.streamlit/`, `teraoka.png`）をGitHubの新規リポジトリにプッシュします。
2. [Streamlit Community Cloud](https://share.streamlit.io/) にGitHubアカウントでログインします。
3. **「New app」**をクリックし、上記のリポジトリとブランチ（main）、`app.py` を指定します。
4. **「Advanced settings」>「Secrets」**に、取得したGroq APIキーを登録します：
   ```toml

   ```
5. **「Deploy!」**をクリックすると、数分で世界中からアクセス可能な公開URL（例: `https://socrates-mentor.streamlit.app`）が発行されます。生徒の端末（スマホやChromebook）へQRコードで配付できます。

## 🔑 5. Groq APIキーの無料取得方法

Groq APIは、オープンモデル（Llama 3.3等）を**完全無料枠**で、圧倒的な高速レスポンス（生徒の待ち時間ほぼゼロ）で提供しています。

1. [Groq Cloud Console](https://console.groq.com/keys) にアクセスし、GoogleアカウントまたはGitHubアカウントでサインアップ（無料）。
2. 左メニューの **「API Keys」** を開き、**「Create API Key」** をクリック。
3. 発行されたキー（`gsk_...` で始まる文字列）をコピーし、アプリ内の設定画面に入力します。
4. ※クレジットカード登録等は不要で、すぐに利用可能です。

## 🔬 6. 大規模言語モデル（LLM）のアルゴリズム解説

高校生がAIをブラックボックスとして盲信するのではなく、情報科学の視点から原理を理解できるように設計されています。

### ① 次トークン予測（Next Token Prediction）の原理
LLMは「思考する知能」というよりも、数式に基づく**「確率統計的な単語予測モデル」**です。
文章をトークン（単語や文字の断片）に分割し、過去の文脈 $x_1, x_2, \dots, x_t$ が与えられたとき、次に来るトークン $x_{t+1}$ の条件付き確率分布 $P(x_{t+1} \mid x_1, \dots, x_t)$ を計算し、最も自然な言葉をサンプリングして出力します。

### ② TransformerとSelf-Attention機構
2017年のGoogle論文「Attention Is All You Need」で発表されたTransformerの中核は**Self-Attention（自己注意機構）**です。
文中のすべての単語ペアについて、Query（検索キー）、Key（照合キー）、Value（意味内容）の3つのベクトルを生成し、以下の数式で行列計算を一括で行います：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

これにより、「彼」「それ」などの指示語が文中のどの単語と結びついているのか、長距離の文脈依存関係を瞬時に並列計算できます。

### ③ 学習の3段階プロセス
1. **事前学習（Pre-training）:** インターネット上の数兆トークンの巨大テキストから次単語を予測する自己教師あり学習。
2. **指示微調整（SFT: Supervised Fine-Tuning）:** 「質問」に対して「回答」を返す対話形式データでの学習。
3. **強化学習（RLHF / DPO）:** 人間の評価に基づいて、より論理的で安全な応答を行うように最適化。

### ④ トークン数確保と途切れ防止制御（要件⑩）
本アプリでは `max_tokens: 3072` を設定し、ソクラテスの問いが途中で不自然に途切れることを防ぎ、必ず完結した日本語の文末（「？」または「。」）で終話する制御を行っています。

## 🧠 7. 「壁打ち対話」で思考が深まる理由（認知科学）

### なぜ「答え」を与えられると頭が悪くなるのか？
人間の脳はエネルギー消費を最小限に抑える性質（**認知の怠惰：Cognitive Miser**）を持っています。
AIから「正解」を与えられると、脳は納得して探索を終了します。しかし、自分の頭で悩み、言葉を絞り出すプロセスを経なければ、脳の神経回路（シナプス）は強化されません。

### 壁打ち対話の3大効用
1. **外化（Externalization）:** 頭の中のモヤモヤした感覚を言語として文字化することで、自分の思考を外から客観視できるようになります。
2. **メタ認知の起動:** 「なぜそう言えるのか？」「前提は何か？」と問われることで、自分の思考の癖や論理の穴に自ら気づきます。
3. **構成主義的学習:** 自らの試行錯誤を通じて掴み取った洞察は、表面的な暗記と異なり、一生消えない真の教養となります。

### 具体例（高校生の活用シーン）
- **探究テーマ:** 「海洋プラスチックを減らしたい」  
  → ソクラテス「分別しない生活者の本当の心理的・物理的ハードルは何だと思う？」  
  → 生徒「意識啓発ではなく、回収ステーションの動線設計にテーマを変えよう！」
- **推薦・志望理由:** 「人を助けたいから看護師になりたい」  
  → ソクラテス「医師や公務員ではなく、なぜ看護師という距離感でなければならないのか？」  
  → 生徒「祖母が入院した際、技術ではなく日常の対話に救われた経験が自分の原点だ！」
- **プログラミング:** 「エラーが出て動かない」  
  → ソクラテス「その関数が実行される瞬間、配列の中身は何個入っていると想定していますか？」  
  → 生徒「あ！要素が0個の時の例外処理が抜けていた！」（ラバーダック効果）

## 🛡️ 8. 完全フロントエンド仕様とプライバシー安全性

本アプリは、生徒が誰にも言えない進路の悩みや、未熟な探究のアイデアを安心して打ち込めるよう、**徹底したローカルセキュア設計**を採用しています。

- **独自バックエンドサーバーなし:** 開発者や学校のサーバーに対話ログが送られて蓄積されることはありません。
- **データはすべてローカル（自身のPC）に保持:** カレンダーのメモや対話履歴はブラウザの `LocalStorage` にのみ格納されます。
- **共有端末でのプライバシー保護:** ブラウザの履歴消去またはシークレットウィンドウを利用すれば、共有端末上に痕跡を残さず利用できます。
- **外部AI規約:** Groq APIはAPI経由で送信されたプロンプトデータをモデルの学習に二次利用しない規約（Zero Data Retention準拠）となっています。
